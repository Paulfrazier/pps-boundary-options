## What this says
- Tubman has a registered passenger elevator (PXH8329).
- Vernon has one registered vertical wheelchair lift (WCL31397) and no registered passenger elevator. The lift's location in the building, travel height and install date were not read (the detail page did not open in the headless browser). Vernon has three levels (LRFP 2021 Vol 2), so a single lift probably does not reach every floor, but this is not confirmed.

## Search scope caveat
The public search matches record numbers, addresses and project descriptions. A negative result is strong but not proof (see ../ada-sabin-irvington/oregon-bcd-elevator-records-sabin.md for the same caveat).
