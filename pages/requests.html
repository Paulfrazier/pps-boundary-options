Model requests

These are best effort boundaries. NOT REAL PLANS, yet.

People ask us to try specific ideas. Each run here was made because someone asked for it. It uses the same model, data and size rules as the example plans, and is compared below with PPS’s plans and the best example we modeled.

A requested run answers one question. It isn’t a recommendation and isn’t one of the example plans. Some requests trade away walking or school sizes to get something else, and the table shows what each one gives up.

Want a run? Describe the idea in a GitHub issue, for example which closures to keep, what to hold fixed and what you’d like improved.
